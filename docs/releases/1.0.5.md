## Momoding 1.0.5

**有新版本，打开 App 就告诉你。**

### 修复

- **更新提醒：** 有新版时，打开 App 会弹窗写清楚更新了什么，点一下就下载安装。选“取消”，这一版就不再提醒。以前只发一条通知，没看到就错过了。
- **国内检查更新拿到旧版：** 通过国内镜像（Gitee）检查更新时，以前只会提示升到 1.0.1；现在会直接提示最新版。
- **等短信的例行任务：** 匹配短信时，按发件人实际的写法来认，不再照搬例子里的说法；“收到短信才开始”的事，改成由短信到达来触发，不再靠定时去等。

### 安装 / 更新

- 从 1.0.1～1.0.4 更新：App 会提醒。旧版本可能先提示一个中间版本，装上后会再提示最新版；也可以直接下载下面的安装包覆盖安装，数据保留。
