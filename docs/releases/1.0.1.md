## Momoding 1.0.1

**这一版之后，更新会自己找上门。** 国内也能收到。

### 新的

- **离开 App 也接着干活**：交代完就可以切走、锁屏。第一次需要时，对话里会请你打开“后台运行”；设置 → 手机权限里也有这一项。一加 / OPPO、小米、vivo、华为会提示开关在哪
- **整理手机里的文件**：说一句“看看下载里有什么大文件”，打开一次“文件”开关，它就能看到整个手机存储，帮你列、找、整理；删除和移动前先问你
- **自动更新**：每天自动看一次有没有新版，有就发通知，点一下更新，对话和设置都保留。先查国内镜像（Gitee），再查 GitHub
- **消息上的状态**：它开始干活时你的消息上出现 👀，做完变 ✅
- **二维码登录**：需要扫码登录的网站，卡片里只显示二维码，刷新会跟着变，扫完自动接着做
- **登录前先看一眼**：已经登着就直接做，登录的每一步先说一句在做什么
- **说话**：卡住时说清楚被什么挡住、试过什么、下一步怎么办；你在聊天里发了密码或验证码，它不会复述，并提醒你之后改掉；替你写的消息按你的语气，你改过的地方记成偏好
- **换模型立即生效**：在设置里换了模型，下一条消息就用新的
- **Shizuku 随 App 附带**（实验性后台屏用）：不用去浏览器下载，点一下弹系统安装
