## Momoding 1.0 预览版

**住在你手机里的办事员。** 交代一句，它用手机上的东西帮你办好，记住你的习惯，替你盯着后续。

这是 Momoding 的新一代：底座换成了 [OpenMinis](https://github.com/OpenMinis/OpenMinis)，在它之上重做了整个产品。

![Momoding](https://raw.githubusercontent.com/1zhangyy1/momoding/main/docs/assets/hero-zh.jpg)

### 能做什么

- **提醒、日程、闹钟**：一句话建好，附"在日历里看"
- **记住你**：说一次偏好，以后办事自动用上
- **缺信息只问一个问题**，不乱猜
- **草稿卡**：替你写短信，你点了"发送"才发出去；用系统短信直接发，一两秒就好。没给发短信权限的话，会打开短信 App 把内容填好
- **上网查**：带回结果和下一步按钮
- **例行任务**：每天定时汇报，没要紧事不打扰
- **动手操作屏幕**（实验性）：打开无障碍后替你操作其他 App。先读界面上的元素、按编号点，必要时才截图，模拟器同一批测试里做对 10/10（旧的纯截图方式是 8/10）。能打开手机上所有带图标的 App，包括微信、美团、电话；"停止"一点就停
- **先问你**：删除、发送、付款前出审批卡，"始终允许"可变成规则
- **看过程**：每条回复都能展开看它做了哪几步
- **权限就地开**：需要屏幕操作时，对话里出一张卡片，直接带你到系统开关；开好回来它会自己接着做。开关是灰色的（APK 安装后系统限制的设置）也会说明怎么解开
- **借屏时不挡手**：它操作屏幕时你照样能点（修了 Android 12 以上全屏透明层挡触摸的问题）
- **后台屏**（实验性）：装了 Shizuku 的手机，它可以在一块看不见的后台屏上操作，不占你的屏幕；目前只在 Android 15 模拟器上验证过
- 首次使用预设 DeepSeek、Kimi、通义千问、智谱、豆包、硅基流动，选一家自动配好对话和看图模型

### 安装

1. 下载下方的 `Momoding-1.0.0.apk`，可以用 `.sha256` 文件核对完整性。安装包用 Momoding 自己的正式签名，证书 SHA-256：`C4:DF:70:5C:61:4B:53:83:36:CC:23:AB:00:0E:F4:D5:D2:AC:F4:8E:80:7D:CE:5D:69:35:A4:C5:D0:31:F9:DB`
2. Android 8.0 及以上
3. **装过旧版 Momoding 的请先卸载**（包括 0.1.0-alpha 和任何测试版）：新版换了底座和签名，不能覆盖升级。之后的版本都用这个签名，可以直接覆盖升级

### 已知情况

- 预览版主要在模拟器和少数真机上测过，国产系统（MIUI/HyperOS、ColorOS 等）的后台保活还在测试，例行任务可能被系统杀掉，需要把 Momoding 加入后台白名单
- "动手操作屏幕"在部分 App 上不稳定
- 中文和英文界面都已打磨过，回复会跟着你说话的语言走；其他语言的部分界面仍是上游原文

遇到问题请[提 Issue](https://github.com/1zhangyy1/momoding/issues/new/choose)，App 里 设置 → 反馈 也能直接打开并自动填好版本和机型。

## Momoding 1.0 Preview

**An assistant that lives on your phone and gets things done.** This release is a new generation of Momoding, rebuilt on [OpenMinis](https://github.com/OpenMinis/OpenMinis).

**What it can do:** reminders, events and alarms from a single sentence; preferences it remembers; one question when a detail is missing; drafts that only go out when you tap Send; web lookups with next-step buttons; daily routines that stay quiet unless something matters; experimental screen operation of other apps through Accessibility (it reads the screen's elements and taps by number, screenshotting only when needed: 10/10 in our emulator test set versus 8/10 for the old screenshot-only approach; it can open every app with a launcher icon, and Stop stops it at once); SMS drafts sent straight through the phone's SMS service; permission cards that take you to the right system switch and carry on afterwards; it no longer blocks your touches while it works; an experimental hidden background screen for phones with Shizuku (verified on an Android 15 emulator only); approval cards before deleting, sending or paying; and a step-by-step view of every task.

**Install:** download `Momoding-1.0.0.apk` below. It needs Android 8.0 or newer. **Uninstall any earlier Momoding build first**: 1.0 is a new codebase with a new signing key, so it can't update the old app in place. Future releases keep this key and update in place. Certificate SHA-256: `C4:DF:70:5C:61:4B:53:83:36:CC:23:AB:00:0E:F4:D5:D2:AC:F4:8E:80:7D:CE:5D:69:35:A4:C5:D0:31:F9:DB`.

**Known issues:** this is a preview. Background reliability on heavily customised Android builds is still being tested. Screen operation is experimental. Chinese and English are polished, and replies follow the language you write in. Other languages still show some upstream text.
