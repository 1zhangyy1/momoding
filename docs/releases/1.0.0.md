## Momoding 1.0 预览版

**住在你手机里的办事员。** 交代一句，它用手机上的东西帮你办好，记住你的习惯，替你盯着后续。

这是 Momoding 的新一代：底座换成了 [OpenMinis](https://github.com/OpenMinis/OpenMinis)，在它之上重做了整个产品。

![Momoding](https://raw.githubusercontent.com/1zhangyy1/momoding/main/docs/assets/hero-zh.png)

### 能做什么

- **提醒、日程、闹钟**：一句话建好，附"在日历里看"
- **记住你**：说一次偏好，以后办事自动用上
- **缺信息只问一个问题**，不乱猜
- **草稿卡**：替你写消息，你点了"发送"才发出去
- **上网查**：带回结果和下一步按钮
- **例行任务**：每天定时汇报，没要紧事不打扰
- **动手操作屏幕**（实验性）：打开无障碍后替你操作其他 App，随时能停
- **先问你**：删除、发送、付款前出审批卡，"始终允许"可变成规则
- **看过程**：每条回复都能展开看它做了哪几步
- 首次使用预设 DeepSeek、Kimi、通义千问、智谱、豆包、硅基流动，选一家自动配好对话和看图模型

### 安装

1. 下载下方的 `Momoding-1.0.0.apk`，可以用 `.sha256` 文件核对完整性
2. Android 8.0 及以上
3. **装过 0.1.0-alpha 版的请先卸载**：新版换了底座和签名，不能覆盖升级

### 已知情况

- 预览版主要在模拟器和少数真机上测过，国产系统（MIUI/HyperOS、ColorOS 等）的后台保活还在测试，例行任务可能被系统杀掉，需要把 Momoding 加入后台白名单
- "动手操作屏幕"在部分 App 上不稳定
- 界面以中文为主，英文可用，其他语言部分界面仍为上游原文

遇到问题请[提 Issue](https://github.com/1zhangyy1/momoding/issues/new/choose)，App 里 设置 → 反馈 也能直接打开并自动填好版本和机型。

## Momoding 1.0 Preview

**An assistant that lives on your phone and gets things done.** This release is a new generation of Momoding, rebuilt on [OpenMinis](https://github.com/OpenMinis/OpenMinis).

**What it can do:** reminders, events and alarms from a single sentence; preferences it remembers; one question when a detail is missing; drafts that only go out when you tap Send; web lookups with next-step buttons; daily routines that stay quiet unless something matters; experimental screen operation of other apps through Accessibility; approval cards before deleting, sending or paying; and a step-by-step view of every task.

**Install:** download `Momoding-1.0.0.apk` below. It needs Android 8.0 or newer. **Uninstall any 0.1.0-alpha build first**: 1.0 is a new codebase with a different signing key, so it can't update the old app in place.

**Known issues:** this is a preview. Background reliability on heavily customised Android builds is still being tested. Screen operation is experimental. The interface is Chinese-first; English works, and other languages still show some upstream text.
