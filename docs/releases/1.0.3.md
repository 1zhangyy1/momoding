## Momoding 1.0.3

**越用越会办事。** 办过的事它会记经验，下次更快；大家验证过的查法，你的 Momoding 也能直接用上。

### 新的

- **记住怎么办事：** 查车票、比价、查办事流程这类要翻网页的事，它会记下哪个网站能用、怎么查最快、哪里会被拦，下次直接照着做。实测同一件事第二次只要第一次一半的时间和花费。
- **社区经验：** 别人验证过的查法会自动拿来用（国内走 Gitee）。你这边办成的好查法，去掉个人信息后会自动分享给大家，审核通过后所有人都能用。不想分享：设置 → 分享经验给社区，关掉即可，也可以直接跟它说。
- **长活不闷着：** 要跑几分钟的活，开头先说一句在做什么，中途说做到哪一步，最后给结论。
- **消息来了自动做事：** 比如“以后快递短信来了，告诉我取件码和驿站”。第一次需要在系统里打开“通知使用权”，对话里会提示。
- **带条件的提醒：** 比如“明早 8 点提醒我交水费，除非我说交了”。你说过交了，到点就不提醒。
- **长对话不忘事：** 对话很长被压缩以后，还记得问了没答、答应了没做的事。
- **大结果不撑爆对话：** 一次查回来特别长的内容会自动存成文件，对话里只留开头，需要时再去读。
- **后台任务更安静：** 后台办完的事在对话里只显示一行“后台办完 · …”，点开看详情。

### 修复

- 更新后第一次打开不再卡一下。
