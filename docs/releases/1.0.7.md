## Momoding 1.0.7

**模型又能换了。** 这一版只修了这一个问题。

### 修复

- **“设置 → 模型”里选不了模型：** 删过服务商又重新加上，或者第一次设置时没走完的话，模型列表能看到，但点哪个都没反应，也没有一个打勾。现在点一下就换成那个模型，正在用的那个会打勾，设置首页也显示正在用的模型，不再显示“没有连接模型”。
- **“操作屏幕”选不了具体模型：** 只配了 OpenAI 这类服务商时，弹出来的选择框里只有“自动”一行。现在会列出这个服务商能看图的模型，最新的排在前面，可以直接选。
