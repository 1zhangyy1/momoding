## Momoding 1.0.10

**交出去的活，现在是一件件“任务”。** 让 Momoding 去查资料、交给某个 Bot 去做，每件事都会在对话里占一行，做完打勾；中途你可以接着聊、补充要求、或者叫停。

### 新功能

- **交出去的活一件一行：** 一次交代几件事，就有几行，各自显示在做、做完或已停止。全部做完，你那条消息才会变成 ✅；还有没做完的，就一直是 👀。
- **边做边聊：** 帮手在干活时，你问别的事，主对话马上回答，不用等它。
- **可以补充，也可以叫停：** 说「只要海南和福建的」，这句话会转给正在做的帮手；说「不用查了」，那件事就停下。
- **先别动：** 说「先别发，等我确认」，这件事上的对外操作会先停住，等你点头才继续。
- **关掉 App 也不丢：** 做到一半 App 被关掉或手机重启，回来后接着做，做完照常回报。发短信、发消息这类对外操作，如果当时没确定发没发出去，会先问你，不会重复发送。
- **出错一定说原因：** 一次回复失败时，你的消息下面会写明为什么，并可以重试。

### 修复

- 用 Anthropic API Key 连 Claude 时，每次请求都会失败，现在可以正常使用。
- 首次启动时如果用 OpenRouter，可能选到已经下线的模型，备用模型还会说它查到了其实没查的内容；现在只会选当前可用、能调用工具的模型。
- 短信草稿发出前，如果那个对话里已经有了新消息，不再发送旧草稿，而是提醒你，并按新消息重新起草。
- 帮手用 wget 读网页时，不再停下来等你批准。
- 定时任务交出去的活在重启后不会丢，回报也会回到原来的对话。

### 变化

- 设置里的「子 Agent」页面去掉了。帮手直接用当前对话的模型，不需要单独配置。
