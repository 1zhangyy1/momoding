# Support

Momoding is a developer preview maintained on a best-effort basis.

- Use GitHub Issues for reproducible bugs.
- Use GitHub Discussions for usage questions and design proposals when Discussions are enabled.
- Use private vulnerability reporting for security issues.

Before posting, remove API keys, project contents, diagnostics archives, device identifiers, local
paths, and account information. Include the commit SHA, Android version, and minimal synthetic
steps to reproduce the problem.
